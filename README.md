# Firefonts

A Firefox extension that changes the font of any site you choose.

Pick a site, switch it on and type a font name. 32 free fonts come with it, from Inter and Lora to JetBrains Mono and Caveat, and the field suggests them as you type. Fonts installed on your computer work too.

Open **Settings** from the popup to choose one font for every site, add a font file you have (TTF, OTF, WOFF or WOFF2), try it on a sentence of your own, and manage your sites.

Each bundled font keeps its own licence, in `src/fonts/licenses/`. The extension's code is MIT.
