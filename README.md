# Firefonts

A Firefox extension that changes the font of any site you choose.

Pick a site, switch it on and type a font name. 34 free fonts come with it, from Inter and Lora to JetBrains Mono and Caveat, and the field suggests them as you type. Fonts installed on your computer work too.

To use a font file you have (TTF, OTF, WOFF or WOFF2), open **Your fonts** from the popup and add it. It then appears first in the suggestions.

Each bundled font keeps its own licence, in `src/fonts/licenses/`. The extension's code is MIT.
